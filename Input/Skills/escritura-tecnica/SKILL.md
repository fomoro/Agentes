# Escritura técnica

Produce documentación breve, verificable y alineada con las fuentes vigentes.

## Método

1. Identifica audiencia, propósito, fuente de verdad y acción que debe permitir el documento.
2. Lee código, configuración, decisiones y evidencia aplicables antes de redactar.
3. Distingue confirmado, supuesto, inferido, riesgo y pendiente cuando cambie una decisión.
4. Redacta el mínimo contenido necesario y enlaza la fuente canónica en lugar de duplicarla.
5. Verifica rutas, comandos, enlaces, ejemplos y consistencia con el estado actual.

Para crear un README desde cero, usa [la plantilla base](templates/README_TEMPLATE.md) únicamente si sus secciones corresponden al proyecto.

## Reglas

- Usa diagramas únicamente cuando aclaren relaciones, secuencias, estados o decisiones.
- Sanitiza ejemplos y no publiques secretos ni datos personales.
- No fuerces un catálogo fijo de documentos; crea solo los artefactos requeridos por el alcance.
- Conserva historial o trazabilidad cuando el cambio afecte operación, contratos o decisiones materiales.

## Criterio de cierre

- La audiencia puede ejecutar o decidir sin ambigüedad material.
- El contenido coincide con las fuentes vigentes y señala sus pendientes.
- No existen enlaces, rutas o ejemplos conocidos como obsoletos.
