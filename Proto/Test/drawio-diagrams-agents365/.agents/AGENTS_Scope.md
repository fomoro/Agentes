# Gobernanza Local - Colcomercio Drawio Agents

## Reglas de Construcción de Diagramas
Antes de diseñar o generar cualquier diagrama en este proyecto, el Agente DEBE obligatoriamente:
1. Leer y aplicar las reglas de arquitectura y comprobación definidas en `theme/guia-construccion.md`.
2. Utilizar estrictamente los colores, geometrías y contenedores definidos en `theme/catalogo-estilos.md`.
3. Aplicar la política de Cero Residuos (*Zero Scratch Waste*), asegurando que cualquier JSON intermedio o script inyector sea eliminado después de usarse.
4. Representar solo la información confirmada o marcarla como pendiente; nunca inventar tramos físicos o componentes.
